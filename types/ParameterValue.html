A ROS 2 parameter value with its type. Every value says what it is, so a write sends exactly that type: the integer 2n and the double 2 cannot be confused, and an empty array still says what it would hold.

Integers are bigint, scalar and in arrays, on every transport, the same as 64-bit integers in decoded messages. On rosbridge the bridge sends integers as JSON numbers, so a value beyond 2^53 has already lost precision before the library converts it.
