What a node says about one parameter name, as read by IProtocolClient.describeParameters. A declared parameter carries its descriptor; 'undeclared' means the node has no parameter by that name.

type is 'not-set' for a dynamically typed parameter that holds no value. integerRange and floatingPointRange are present only when the node declared one; a write outside the range is refused by the node.
