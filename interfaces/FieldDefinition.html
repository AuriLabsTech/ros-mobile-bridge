Optional defaultValue

defaultValue?: DefinitionValue | DefinitionValue[]

Set only when the schema declares a default (float64 w 1.0). A scalar has the JavaScript type a decoded message gives that field (a 64-bit integer is a bigint); an array default is a plain array of those. A 64-bit default above 2^53 in an IDL schema is left out: the IDL parser has already rounded it.
