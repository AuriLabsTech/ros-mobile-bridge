Optional onFeedback

onFeedback?: ((feedback) => void)

Per-goal progress callback, registered at dispatch time (the shape every native ROS 2 action client uses). Called with the action's feedback payload (the <Action>_Feedback message) as decoded JSON.

The contract is best-effort progress: the newest state wins under pressure, and there is no rate guarantee. Feedback is expected to be sampled-shaped (each frame restates current progress; the terminal outcome travels separately), so a skipped frame is restated by the next one. Consumers who need every frame subscribe to the action's feedback topic themselves.

A callback that throws is logged and never affects the goal or the connection. No feedback is requested from the bridge when this option is omitted.
