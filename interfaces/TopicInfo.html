Interface TopicInfo

A topic the connected server currently knows about, as returned by IProtocolClient.getAvailableTopics and passed to onTopicsChange.

  • Foxglove WebSocket: the channels the bridge has advertised to this client; the list changes when the bridge advertises or unadvertises.
  • rosbridge: the answer of the robot's /rosapi/topics service, asked on connect, on the discoveryRefreshMs timer, and on each getAvailableTopics() call while connected.

encoding

The encoding the server declared for this topic: 'json' on rosbridge; on Foxglove WebSocket whatever the bridge declares, usually 'cdr'. The same value RosMessage.encoding carries for this topic.

Optional source

source?: TopicSource

Whether this client publishes to the topic (see TopicSource), read from the client's own state each time a list is handed out. getAvailableTopics() reflects a publish, ensureAdvertised or unadvertise at once. These calls do not fire onTopicsChange, which reports changes to the server's list, so a listener sees the new value with the next such change. A topic only this client publishes appears once the server lists it; after unadvertise, rosbridge can keep listing it, as 'robot', for about 10 s while the bridge holds its publisher.
