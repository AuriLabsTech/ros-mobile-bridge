Interface SubscriptionStats

Snapshot of the adaptive-throttle state for one subscription. Surfaced so consumers can show users when delivery is being capped below what they requested (e.g. a "5 Hz" / "1 Hz" / "0.5 Hz" badge near a widget). adaptiveMinIntervalMs > 0 means the throttle is actively limiting.

interface SubscriptionStats {
    adaptiveMinIntervalMs: number;
    bucketLabel: string;
    bytesPerSec: number;
}
